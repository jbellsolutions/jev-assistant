# Security and private data

Jev can act on the computer and accounts selected by its user. The companion binds loopback. Do not publish that port or bypass its origin/authentication checks to make remote access work.

Credentials and task data stay in the user's private Jev home, outside the application bundle. Releases include no keys, cookies, sessions or paired extension configuration. Never paste credentials into a public issue. Report security problems privately using GitHub's private vulnerability reporting if enabled, or contact the repository owner without posting secret-bearing logs.

Cloud agents and arbitrary websites cannot provide a universal exactly-once guarantee. Inspect uncertain external actions before repeating them. Each user controls Mac/Chrome permissions and app authorization. Phone access requires its own secure pairing and session design.
