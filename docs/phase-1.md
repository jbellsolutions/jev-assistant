# Phase 1 handoff — October 26, 2026

## Closed scope

The desktop experience was accepted by its owner. Phase 1 includes the Electron app, local companion, Chrome extension, LiveKit/GPT-Live conversation, TypeSafe judgments, Luna reasoning, saved tasks, explicit computer targets, cloud-browser cleanup, credential editing, Orgo access, and optional Composio app-tool setup.

The release adds a larger side-by-side workspace, compact toggle, remembered window size, a first-run checklist and a Mac Installer package that carries the separate Mac-control helper. End users do not build code or install Node.

## Distribution status

Version 1.0.0 is published as a **preview**, with a public source repository and download. It is not a signed/notarized general release. Apple signing/notarization and Chrome Web Store distribution are the remaining steps toward a fully smooth nontechnical installation. Account setup and OS permission approval remain user-owned steps.

Supported preview target: Apple Silicon Mac, macOS 15+. Credentials, local accounts, private notes, device IDs and saved browser state do not ship.

## Deliberate next phase

- A private, paired iPhone web companion saved to the Home Screen.
- Apple signing/notarization and Chrome Web Store publishing.
- Authenticated application workflow and recovery checks on representative tasks.
- Connection checks, clearer account selection and measured cost/latency.
- An always-on host only if cloud tasks must continue when the Mac is asleep.

This handoff closes the accepted desktop phase; it does not claim that the full mobile/project-orchestration acceptance list is complete.
